# 🌱 Breathe ESG Assignment

## 🚀 Features
✅ Upload CSV files  
✅ Store company information  
✅ Process ESG emission data  
✅ React frontend integration  
✅ Django REST API backend  
✅ SQLite database support  

---

## 🛠️ Tech Stack

### 🎨 Frontend
- ⚛️ React.js
- 📡 Axios
- 🎨 CSS

### 🔧 Backend
- 🐍 Python
- 🌐 Django
- 🔌 Django REST Framework

### 🗄️ Database
- 💾 SQLite

---

breathe-esg-assignment/
│

---

## ▶️ Run Backend

```bash
cd backend
python manage.py runserver
```

Backend runs at:

```bash
http://127.0.0.1:8000
```

---

## ▶️ Run Frontend

```bash
cd frontend
npm start
```

Frontend runs at:

```bash
http://localhost:3000
```
